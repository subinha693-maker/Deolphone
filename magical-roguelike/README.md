# 황혼의 마법소녀 원정대 — 분기형 탐사 마법소녀 로그라이크 (프로토타입)

2D 횡스크롤 자동 전투 + 분기형 탐사 맵 + 유물 시너지를 결합한 로그라이크 파티 RPG의 플레이 가능한 MVP입니다.
빌드 도구 없이 순수 HTML5 Canvas + JavaScript로 동작합니다.

## 실행 방법

```bash
cd magical-roguelike
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 파일로 직접 열어도 동작합니다(모듈/fetch를 사용하지 않음). 글꼴(Gowun Batang)만 인터넷이 필요하며, 없으면 기본 명조체로 표시됩니다.

로직 테스트(브라우저 불필요):

```bash
node tests/run-tests.js
```

스프라이트/UI 리소스 재생성(원본 시트는 `tools/source/`):

```bash
pip install pillow numpy scipy
python3 tools/extract_sprites.py   # 캐릭터 시트 → assets/sprites/*.png + js/data/spriteData.js
python3 tools/extract_ui.py        # 대화창/선택지 참고 이미지 → assets/ui/*.png
```

## 조작

| 동작 | 방법 |
| --- | --- |
| 경로 선택 | 탐사 맵에서 빛나는 노드 클릭 → `진입` |
| 스킬 | 배치 카드의 스킬 버튼, 또는 `Q` `W` `E` `R` (상단 전열/후열, 하단 전열/후열) |
| 교대 | 대기열 카드 클릭 → 배치 칸 클릭 (반대 순서도 가능) |
| 진형 변경 | 진격로 오른쪽의 `⇄ 진형` (전열 ↔ 후열) |
| 진격로 이동 | 배치 카드의 `↕` (2초간 전투 이탈 후 다른 진격로 도착) |
| 일시정지 / 배속 | `Space` / 상단 `속도 ×1·×2` |
| 유물·시너지 목록 | 상단 `유물 · 시너지` 버튼 |
| 탐사 맵 편성 / 물약 | 맵 하단 파티 카드 두 장을 차례로 클릭해 자리 교환, `⚱` 로 물약 사용 |

## 구현된 기능

- **게임 상태 머신** (`GameManager`): TITLE → MAP → NODE_ENTER → BATTLE/EVENT/REST/RELIC → REWARD → NODE_COMPLETE → MAP / RUN_CLEARED / RUN_FAILED. 허용되지 않은 전환은 거부됩니다.
- **전투 노드 흐름** (`WaveManager`): 전진(달리기 모션 + 배경 스크롤) → 적 출현·자동 전투 → 웨이브 클리어 → 재전진 → … → 노드 클리어 → 보상. 전투 페이즈도 별도 상태 머신이며, 웨이브 종료는 "스폰 완료 + 생존 적 0"으로만 판정합니다(애니메이션 종료와 무관).
- **분기형 탐사 맵** (`MapManager`): 8개 스테이지, 분기·합류 보장, 노드 상태(완료/현재/선택 가능/잠김/지나침) 표시, 난이도·위험도·보상 정보.
  - 구현 노드: 일반 전투, 방어전(홈 포인트), 강적 전투, 유물, 사건(5종), 휴식, 최종 전투(보스).
- **두 진격로** (`LaneManager`): 상단/하단 적이 독립적으로 이동·공격. 진격로별 위험도/적 수/접근 중 수/거리 UI.
  - 방어전 노드: 빈 진격로를 지나 홈 포인트에 닿은 적만큼 공유 생명 감소, 0이면 탐사 실패.
  - 일반 전투 노드: 빈 진격로의 적은 진형 경계에서 "대기"하며, 아군을 보내 처치해야 웨이브가 끝납니다.
- **파티/교대/진형** (`PartyManager`, `FormationSystem`): 선발 3 + 대기 3, 교대 대기시간 5초, 퇴각 시 체력 유지, 전투 불능 아군 투입 불가, 진격로 이동 시간 2초, 전열/후열 교체(전열이 피격 대상, 후열 근접형은 피해 60%).
- **자동 전투** (`CombatSystem`): 근접형은 콤보 모션, 원거리형은 투사체 모션 + 실제 투사체. 피해는 애니메이션의 타격 시점에 적용.
- **스킬 6종** (`SkillSystem`): 단일(로젤), 광역(루나), 보호막+감속(실피), 회복(아모레), 기절+방어(벨라), 교대 연계(청련: 8초 안에 그 진격로로 교대하면 대기시간 무시 + 공격력 증가, 패시브 `선풍 진입`).
- **유물 13종 / 시너지 6종** (`RelicSystem`, `js/data/relics.js`): 요청한 초기 유물 6종(잔불의 핵, 공명의 문양, 연쇄의 인장, 수호자의 파편, 추격자의 메달, 잔향의 수정) 포함. 전투 이벤트(전투 시작, 웨이브 시작/종료, 기본 공격 적중, 스킬 적중, 처치, 피격, 교대 완료) 기반.
  - 중복/무한 발동 방지: 이벤트 중첩 깊이 제한(3), 유물이 준 피해는 다시 적중 이벤트를 만들지 않음, 폭발로 처치한 적은 다시 폭발하지 않음.
  - 시너지 UI: 보유 유물, 개별 효과, 시너지 조건 진행도(✔/✗), 활성 여부, 전투 중 발동 횟수, 발동 시 플로팅 텍스트와 아이콘 점멸.
- **보상** (`RewardSystem`): 유물 3택 + 회복 / 정찰(다음 전투 적 체력 -15%) 중 1택, 별조각 자동 지급. 강적 노드는 희귀 유물 확률 ↑.
- **사건·휴식 화면**: 제공된 고딕 리본 대화창/선택지 이미지를 잘라 사용 (`assets/ui`).
- **승리/패배 화면과 재시작**.
- **캐릭터 애니메이션**: 제공된 6장의 시트를 잘라 대기·걷기(3)·근접 콤보(4)·회전 공격(4)·투사체(4)·피격/쓰러짐(3) 프레임으로 사용. 투사체/폭발 프레임은 투사체·타격 이펙트로 재사용.
- **데이터 분리**: 캐릭터, 적, 유물, 시너지, 노드, 웨이브, 사건이 모두 `js/data/`에 있으며 수치·이름을 코드 수정 없이 조정 가능.

## 코드 구조

```
js/core/      util(RNG, EventBus) · StateMachine · GameManager
js/data/      config · characters · enemies · relics · nodes(웨이브 포함) · events · spriteData(생성됨)
js/systems/   ExplorationManager · MapManager · NodeManager · WaveManager(+Battle) · LaneManager
              PartyManager · FormationSystem · CombatSystem · SkillSystem · RelicSystem · RewardSystem
js/ui/        Assets · BattleRenderer · SceneArt · UIManager
tests/        run-tests.js (DOM 없이 로직 검증 21개)
tools/        extract_sprites.py · extract_ui.py · source/(원본 이미지)
```

시스템 코드는 DOM에 접근하지 않으므로 Node에서 그대로 테스트할 수 있습니다.

## 아직 없는 기능 (의도적으로 표시하지 않음)

- **상점 노드**: `NODE_TYPES.shop`은 `implemented: false`로 데이터 구조만 있고, 맵에 생성되지 않습니다.
- **영구 성장 / 해금 / 메타 진행**: 없음. 실패 시 무엇을 유지할지는 `MG.FAILURE_POLICY`(`js/data/config.js`)로 분리해 두었으며 현재는 전부 초기화됩니다.
- 사운드, 저장/불러오기, 아군 영입·레벨업, 적 전용 스프라이트 시트(적은 코드로 그린 픽셀 아트), 다중 탐사 구역.

## 알려진 문제 / 한계

- 밸런스는 프로토타입 수준입니다. 수치는 `js/data/`에서 조정하세요.
- 적은 직접 그린 소형 픽셀 아트이며 공격 모션은 돌진(lunge)과 점멸 정도만 있습니다.
- 캐릭터 시트는 이미지 자동 분할이라 일부 프레임(예: 아모레 근접 3번)에 원본 격자선 흔적이 약간 남아 있습니다.
- 유물 아이콘은 유니코드 기호라 OS 글꼴에 따라 모양이 다를 수 있습니다.
- 화면은 1280×720 고정 비율로 창 크기에 맞춰 축소/확대됩니다(모바일 터치 최적화는 하지 않음).
