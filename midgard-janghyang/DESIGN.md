# 미드가르드 제도: 잔향 — v2.0 확장 설계·검증 기록

`index.html` 한 파일로 실행된다(외부 의존성 없음, 스마트폰 대응). 이 문서는 무엇을 왜 바꿨는지와 어떻게 검증했는지를 정리한다.

## 1. 기존(v1) 분석과 문제점

| 영역 | v1 상태 | 문제 |
|---|---|---|
| 장비 | 고정 장비 11종, 슬롯 2개, 연으로 구매 | 수치 차이뿐, 전투 방식 변화 없음. 모두 사면 끝 |
| 임시 강화 | 19종, 전부 능력치형 | 규칙 변화·시너지 없음 |
| 지도 | 6~7구역 직선, 구역마다 2~3개 중 택1 | 경로 개념이 없고, 매판 비슷함 |
| 사건 | 17종 | 지역·종족 반영 없음, 후속 분기 거의 없음 |
| 보스 | 2종, 일반 적과 같은 행동 구조 | 공략법 차이 없음 |
| 종족·지역 | 4종족, 2지역 | 반복감 |
| 성장 | 영구 강화 5종 + 장비 | 후반에 연 소비처가 사라짐 |

## 2. 시스템 연결 구조

```
탐사(무작위 갈래 지도·노드) ─ 전투/사건 ─▶ 연·기록·소재·잔해·현장 장비·유물
   │                                         │
   │  유물 태그 + 이상구 형태 태그 + 잔해 태그 ─▶ 시너지(9종 × 2단계)
   │                                         │
   └── 철수/완수 ─▶ 본부: 아틀리에 제작·개조 / 기술 개발 / 시설 / 훈련 / 도감 달성
                     └─▶ 다음 탐사: 위험도·의뢰·출발 지원 선택 → 해금 지역·종족·보스 유물 증가
```

## 3. 구현 내용

### 장비·아틀리에
- 슬롯 4개: 이상구 · 방호구 · 보조구 · 잔해 장신구.
- 형태 17종이 전투 방식을 결정한다. 예: 단검은 2회 타격, 장창은 방어 자세·은신 무시, 둔기는 균열로 행동 끊기, 총은 탄창과 재장전, 사슬낫은 출혈, 공명기는 고유 능력 특화, 도검은 반격.
- 등급: 일반 / 정련 / 희귀 / 이형 / 유일(보스). 등급에 따라 주요·부가 옵션 칸과 잔해 결합 가능 여부가 달라진다.
- 제작은 형태 → 등급 → 기본 소재(8종) → 잔해(23종) → 주요 옵션(9) → 부가 옵션(15) → 부작용(8, 감수하면 주요 옵션 칸 +1) 순서다. 모바일에서는 칩을 눌러 고르는 한 화면 구성이고, 미리보기·비용·부족 사유를 함께 보여 준다.
- 개조: 강화 +2/+5/+8(기술 단계별), 옵션 교체, 부가 옵션 1회 추가, 부작용 정화, 분해.
- v1 장비 11종은 같은 이름·비슷한 효과의 v2 장비로 옮겼다(`LEGACY_GEAR`).

### 후반 소비처
아틀리에 기술 15종, 소재 정제, 본부 시설 6종, 엽사 훈련 9종(행동 기술·상시 기술, 장착 칸 제한), 위험도 0~5, 의뢰 게시판 10종, 출발 지원 4종(탐사마다 쓰는 반복 소비처), 장비 강화 +8, 도감 달성 15종을 넣었다.
영구 강화(v1)는 그대로 유지한다.

### 지도·노드
- 갈래 지도: 행마다 2~4개 노드가 인접 노드와 연결된다. 진입 / 일반 / 위험 / 중간 / 고위험 / 준비 / 최종 역할에 따라 등장 확률이 다르고, 지역 환경과 위험도에 따라 다시 보정된다.
- 생성 규칙
  - 휴식처는 연속으로 나오지 않고 개수에 상한이 있다.
  - 준비 구역에는 항상 휴식처가 있다.
  - 중반에 휴식처·보급소가 하나도 없으면 하나를 보정해 넣는다.
  - 정예는 3구역부터 나온다.
  - 지름길은 준비 구역을 넘지 않는다.
- 신규 노드: 아틀리에 잔해, 이상체 격리 시설(선택형 보스), 거래상, 연구 시설(유물 중첩 강화), 의뢰 현장, 위험한 지름길, 저주받은 보물고, 특수 사건.
- 미확인 노드, 조건부 보상(4라운드 처치 등), 사건으로 열리는 숨겨진 경로(둥지·보관함), 조건부 숨겨진 최종 위협을 넣었다.

### 임시 강화와 유물
- 역할을 나눴다. **임시 강화**(일반 전투 보상)는 능력치 조정, **유물**(정예·보관함·거래상 등)은 규칙 변화를 맡는다.
- 유물 66종의 구성
  - 일반·희귀·이형 41종
  - 지역 전용 5종
  - 보스 15종 (해당 보스를 처치하면 등장 풀에 추가)
  - 저주 5종
- 중첩해서 강화할 수 있다.
- 시너지 9종(치명·수호·발현·출혈·보급·잔향·사냥·탐욕·혈투), 각각 2개·4개 단계. 4개 단계는 처형, 축적 반격, 폭주 전환, 메아리 같은 새 규칙을 연다.
- 선택 화면에서 "치명 3→4 Ⅱ 발동!"처럼 시너지 변화를 미리 보여 준다.

### 보스
15종, 각자 고유 기믹이 있다.
- 메아리 반사, 은신·기습, 초대 누적, 카운트다운·되감기
- 빛과 어둠, 수위, 포자 군락, 감염, 공정 순서 공개·가속
- 적응, 잔상 장막, 행동 봉인 예고, 다른 보스 기믹 탈취, 수면·각성
- 이상체화한 조사원

지역마다 2종 중 하나가 무작위로 나오며, 직전에 만난 보스는 덜 나온다. 다시 만나면 변이 6종 중 일부가 붙는다.
모든 기믹은 행동 예고와 공략 힌트로 알려 준다. 공격과 방어는 동시에 봉인되지 않는다.

### 종족
기존 4종에 설정집의 17종족 중 에레비아와 맞는 4종을 더했다.

| 종족 | 플레이 스타일 | 해금 조건 |
|---|---|---|
| 타비족 | 회피·연속 타격 | 탐사 완수 |
| 레프족 | 예고 읽기·받아치기 | 이상체 12종 발견 |
| 메라키족 | 자원 운용·교란 | 유물 12종 발견 |
| 아이벤족 | 고부담 유지 | 흉형 이상 5체 처치 |

종족별 사건 선택지와 반응 텍스트도 넣었다.

### 지역
기존 2곳에 5곳을 더했다.

| 지역 | 환경 효과 |
|---|---|
| 무너진 남부 항구 | 물에 잠긴 바닥 |
| 포자 오염 구역 | 이동 시 부담 증가 |
| 폐쇄된 캡슐 연구동 | 경보 단계 |
| 잿빛 거리 | 잔향 반향 |
| 메디치 격리 보관소 | 감시 |

신규 지역마다 이상체, 전용 사건, 전용 소재·유물, 보스 2종, 지역 기록 3편이 있다.

## 4. 설정 구분 원칙
게임 안의 `[설정집 확정] / [설정집 미정] / [게임 오리지널]` 표기와 도감의 「설정 구분」 탭을 갱신했다.
- **설정집 내용을 그대로 쓴 것**: 종족 외형과 거주지, 조직의 성격, 재형과 부르가 강제 토벌, 지형 이상 시체의 보고 의무, 아르고의 1km 항해 범위.
- **게임 오리지널**: 신규 지역의 사건·보스, 지역 기록.
- **설정집 미정이라 정하지 않은 것**: 에레비아 건축 양식, 관리자의 정체, 현재 건년.
- **재형**: 설정상 흑~백 등급 엽사만 상대하므로 전투에 넣지 않았다.

## 5. 저장 호환
- 저장 키 `midgard_janghyang_v2`.
- v1 키가 있으면 자동으로 v2로 옮긴다(`migrateV1`). v1 키는 백업으로 남긴다.
- 진행 중인 탐사(전투·사건 포함)는 v1 지도를 v2 갈래 지도로 바꿔 이어서 할 수 있다.
- 손상된 탐사 데이터는 전체를 초기화하지 않고 그 탐사만 취소한다.

## 6. 검증 (Playwright 자동화)
- **자동 플레이 봇**: 최종 빌드로 4세션, 탐사 647회를 진행했다. 예외 0건, 멈춤 0건. 같은 지도는 한 번도 나오지 않았다(탐사 수 = 서로 다른 지도 수). 일반 보스 14종이 모두 등장했고, 조건부 보스(조사원이었던 것)는 별도 시나리오로 출현과 처치를 확인했다.
- **전수 테스트**: 모든 사건 선택지 × 8종족, 동적 노드 13종 × 7지역, 장비 형태×소재×등급 조합, 유일 장비, 잔해, 모든 유물을 최대 중첩한 상태에서 적 44종과 전투. 오류·NaN 0건.
- **지도 생성 300회**: 모든 노드에 도달할 수 있고, 막다른 길이 없다. 휴식 약 1.7 / 보급 약 1.6 (지도당).
- **시너지 밸런스 시뮬레이션**: 같은 캐릭터에 한 태그의 유물 4개를 주고 보스전을 치렀다. 무유물 기준 체력 손실 43% 대비, 각 빌드는 18~34%이며 탐욕·보급처럼 경제·지속력 쪽은 기준에 가깝다. 수치를 두 차례 하향했다. 출혈 빌드는 13→19%, 수호 빌드는 15→18%가 되었다.
- **v1 → v2 이전**: 원본 v1 파일로 만든 저장(본부·전투 중·사건 중)을 불러와 끝까지 진행했다.
- **모바일**: 360px 폭 주요 화면 14종에서 가로 넘침 0건, 터치 영역 최소 높이를 확인했다. DOM 무작위 클릭 2,500회에서 오류 0건.

## 7. 알려진 한계
- 보스 15종과 지역 7곳의 수치는 자동 봇·시뮬레이션 기준으로 맞췄다. 실제 손으로 하는 플레이의 체감 난도는 추가 조정이 필요할 수 있다.
- 탐사를 수십 회 하면 연이 남기 시작한다. 이때는 출발 지원·장비 강화(+8)·재제작이 계속 쓰는 소비처다. 그래도 남는 정도는 플레이 성향에 따라 다르다.
