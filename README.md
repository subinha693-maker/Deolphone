# 덜폰 (DeolPhone)

스크린타임을 자동으로 읽고, 요일별 일정에 맞춰 앱을 잠그는 안드로이드 앱 (Android 10 이상).

## 기능

### 오늘 / 주간
- 오늘 총 사용 시간 vs 하루 목표, 잠금 해제 횟수, 앱별 사용 시간
- 오늘의 규칙 상태 (지금 잠금 중인지, 허용 시간이 얼마나 남았는지)
- 최근 7일 막대그래프, 하루 평균

### 일정
- **잠금 시간대**: 요일 + 시간대 + 대상 앱 (예: 평일 22:00 ~ 다음날 07:00, 모든 앱)
- **허용 사용량**: 요일 + 하루 허용 시간 + 대상 앱 (예: 주말 유튜브·인스타 합쳐서 1시간). 다 쓰면 자정까지 잠김
- 대상 앱은 "모든 앱" 또는 "고른 앱" (고른 앱들은 사용 시간을 합쳐서 계산)
- **항상 허용 앱**: 어떤 규칙에도 잠기지 않음. 전화·문자·설정·키보드·홈 화면은 원래 잠기지 않음
- 잠긴 앱을 열면 홈으로 보내고 멈춤 화면 표시. "5분 더 쓰기"는 15초 기다려야 눌림

### 설정 화면 차단
- 잠금 시간대이거나 엄격모드 중일 때, 설정·권한·설치 관리 화면에 **"덜폰"이 보이면 즉시 홈으로 튕김**
  (권한 끄기, 앱 정보·강제 중지·데이터 삭제, 접근성 끄기, 삭제 방지 끄기, 앱 삭제 등)
- 엄격모드 중에는 날짜·시간 설정, USB 디버깅 화면도 막음
- "다른 앱 위에 표시" 권한은 아예 쓰지 않음 → 그 알림 자체가 뜨지 않음

### 엄격모드
- 시작(지금 / 날짜 지정)과 끝(날짜 + 시각)을 직접 정함. 확인 문구를 입력해야 시작
- 시작하면 끝날 때까지 **해제·단축·취소 불가**. 예약만 해둔 것도 취소 불가
- 기간 중에는 규칙 수정·삭제, 항상 허용 앱 추가, "5분 더" 모두 불가
- 가능한 것: 새 규칙 추가, 기간 연장 (더 엄격해지는 방향만)
- 폰 시계를 바꿔서 빨리 끝내는 것도 막음 (부팅 후 경과 시간 기준으로 계산)

모든 기록과 설정은 폰 안에만 저장되고, 인터넷 권한이 아예 없습니다.

## 막을 수 없는 것 (솔직하게)
일반 앱으로는 다음까지는 막지 못합니다: 안전 모드로 재부팅(모든 외부 앱이 꺼짐), 공장 초기화,
엄격모드 전에 이미 켜둔 USB 디버깅으로 PC에서 지우기. 엄격모드 시작 전에 USB 디버깅을 꺼두세요.

## APK 만드는 법

### 방법 1: PC + Android Studio
1. Android Studio 설치 → `Open` 으로 이 폴더 열기 (처음엔 필요한 파일을 받느라 몇 분 걸림)
2. `Build → Build APK(s)` → `app/build/outputs/apk/debug/app-debug.apk` 를 폰으로 옮겨 설치
   (또는 폰을 USB로 연결하고 ▶ 실행)

### 방법 2: PC 없이 GitHub로
1. GitHub 저장소에 이 폴더 내용을 그대로 올리기
2. `Actions` 탭에서 "Build APK" 가 자동 실행됨 (약 5분)
3. 완료된 실행 → 맨 아래 `DeolPhone-apk` 다운로드 → 압축 풀고 `app-debug.apk` 설치

## 처음 설정 순서

| 순서 | 권한 | 어디서 |
|---|---|---|
| 1 | 사용 기록 접근 (필수) | 앱 첫 화면 버튼 |
| 2 | 덜폰 보호 기능 (접근성, 잠금에 필수) | 일정 탭 → 보호 기능 |
| 3 | 삭제 방지 (엄격모드에 필수) | 일정 탭 → 보호 기능 |
| 4 | 알림 (선택) | 일정 탭 → 보호 기능 |

**스위치가 회색으로 막혀 있으면** (안드로이드 13 이상, 직접 설치한 앱):
설정 → 애플리케이션 → 덜폰 → 오른쪽 위 ⋮ → **제한된 설정 허용** 을 먼저 누른 뒤 다시 켜세요.

**삼성 폰**: 배터리 → 백그라운드 사용 제한에서 덜폰을 "제한 없음"으로 두세요.

## 파일 구조

```
app/src/main/java/com/deolphone/app/
  Rules.kt            규칙 모델·저장, 엄격모드, 조작 방지 시계, 항상 허용 앱 목록
  GuardService.kt     보호 기능: 앱 잠금, 설정 화면 차단, 목표 알림
  AdminReceiver.kt    삭제 방지
  UsageRepo.kt        사용 기록 읽기·앱별 시간 계산
  BlockActivity.kt    멈춤 화면
  Screens.kt          오늘 / 주간 화면, 공용 컴포넌트
  ScheduleScreens.kt  일정 화면, 규칙 편집, 엄격모드 시작·연장
  Prefs.kt            목표·허용 앱·5분 더
  Permissions.kt      권한 확인
  Notifications.kt    알림
```
