# 심연의 계단 (텍스트 로그라이크 RPG)

`index.html` 하나로 브라우저에서 바로 실행됩니다. 폰 세로 화면 기준으로 만들었습니다.

## 현재 버전 (작은 버전)
- 직업 3개: 전사 · 마법사 · 도적 (스킬 3개 + 패시브)
- 1층 "축축한 지하묘지": 9구역, 몬스터 6종 + 미믹 + 보스(해골 왕 바르굼). 보스를 잡으면 같은 층이 더 강해진 심층으로 계속 내려감
- 갈림길: 전투 / 정예 / 사건 / 상점 / 연금술사 / 휴식 / 보물
- 행동 순서: 민첩 + 주사위(1~10), 상대의 2배 이상이면 추가 행동
- 상태이상 11종 + 버프, 속성 상성(불→얼음→번개→불, 신성↔암흑)
- 아이템: 소모품 22 · 무기 10 · 방어구 8 · 악세사리 9, 등급(일반/희귀/전설/저주)
- NPC: 상인 모르크, 연금술사 이브(숨은 레시피 15개)
- 사건 7개 (스탯 판정·운 선택지 포함)
- 레벨업 강화 22종 중 3개 제시. 죽으면 레벨만 남고, 레벨이 높으면 시작할 때 "베테랑" 강화를 고름
- 진행 상황은 브라우저 localStorage에 저장 (구역 이동마다 자동 저장)

## 콘텐츠 늘리기
`<script>` 맨 위 데이터 영역의 객체에 항목을 추가하면 됩니다.
`CLASSES`, `SKILLS`, `MONSTERS`, `FLOORS`, `ITEMS`, `RECIPES`, `NPCS`, `EVENTS`, `PERKS`, `STATUSES`
