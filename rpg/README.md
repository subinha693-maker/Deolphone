# 심연의 계단 (텍스트 모험 RPG)

`index.html` 하나로 브라우저에서 바로 실행됩니다. 폰 세로 화면 기준.

## 진행 방식
- 월드맵에서 맵을 고르고 → 맵 안의 지역으로 들어가 → **탐색**을 누르면 주인공이 걸어가고, 확률에 따라 몬스터·아이템·골드·보물상자(가끔 미믹)·사건·약초가 나옵니다.
- 지역마다 탐색도가 있고, 100%가 되면 보스에게 도전할 수 있습니다. 보스를 쓰러뜨리면 다음 지역이나 다음 맵이 열립니다.
- 레벨업마다 모든 스탯이 오르고, 강화 3개 중 1개를 골라 영구히 얻습니다.
- 죽으면 마지막으로 들른 마을에서 깨어나고 골드 20%를 잃습니다. 레벨·장비는 그대로입니다.
- 빅토리아 성의 그림자 왕 녹턴을 쓰러뜨리면 1회차 클리어. 들바람 마을 장로의 **시간의 석판**으로 다음 회차를 시작합니다.
  - 레벨·스탯·강화·장비·소모품·골드·레시피는 유지, 지역 진행·보스·배표는 초기화
  - 일반 맵의 적은 회차마다 Lv +15, 회차 보너스로 공격·방어·마력·HP +5%
- 다회차 지역(회차가 올라도 약해지지 않음): 오팔 강변(2회차~), 바다(3회차~, 남부두 배표 필요), 해안 휴양지(4회차~)
- 끝없는 탑: 층마다 수호자를 쓰러뜨리며 끝없이 올라가는 곳

## 월드맵 (사용자 스케치 기준)
들바람 마을(시작) · 동쪽 생명 숲 · 이상한 버섯 숲 · 마법사들의 마을 · 오팔 강변 · 장미 마을 · 남부두 마을 · 바다 · 해안 휴양지 · 기사들의 마을 · 끝없는 탑 · 빅토리아 광장 · 빅토리아 시가지 · 빅토리아 성

## 콘텐츠 늘리기
`<script>` 맨 위 데이터 영역의 객체에 항목을 추가하면 됩니다.
`MAPS`(맵·지역·시설), `MONSTERS`(Lv1 기준 스탯, `sprite`로 도트 지정), `SPRITES`(3프레임 가로 띠 PNG), `ITEMS`, `RECIPES`, `EVENTS`, `PERKS`, `CLASSES`, `SKILLS`, `STATUSES`, `THEMES`(탐색 장면 배경)
